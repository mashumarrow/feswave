# ESP32 2台のWi-Fi RSSIマッピング実験

ESP32-WROOM-32D搭載開発ボード2台とWi-Fi対応スマホで、このスマホの信号が左右どちらの受信機で強いかを表示する。左のESP32がアクセスポイントとWebサーバーを兼ねる。外部ルーター、インターネット、スマホアプリは不要。2台とも基板アンテナを使う。

## 書き込み

USBシリアル付きの4 MB開発ボード（PlatformIOの `esp32dev`）を想定。モジュール単体の場合は3.3 V電源と書き込み回路が別途必要。

PlatformIO IDEでこのディレクトリを開き、左用のボードには環境 `left`、右用には `right` の Upload を実行する。CLIの場合はこのディレクトリで次を実行する。1台ずつUSB接続するとポートを取り違えにくい。

```sh
pio run
pio device list
pio run -e left -t upload --upload-port /dev/ttyUSB0
# ボードを右用に差し替え、ポート名を確認
pio run -e right -t upload --upload-port /dev/ttyUSB0
```

## 試し方

1. 左右のボードを例として3 m離し、アンテナを同じ向き・高さにして給電する。
2. スマホをWi-Fi **FESWAVE-RSSI**（パスワード **feswave-test**）に接続する。「インターネットなし」と表示されても接続を維持し、ブラウザで **http://192.168.4.1/** を開く。
3. 「右受信機 接続中」と左右それぞれのdBm値を確認する。中央でスマホの向きを固定し、値が落ち着いたら「ここを中央として補正」を押す。補正はページを閉じるか再読み込みすると解除される。
4. 画面を開いたまま左端→中央→右端と移動し、各地点で数秒止まる。左右のdBm、推定、表示が切り替わるまでの時間を比較する。スマホの向きや人の立ち位置を変えて繰り返すと遮蔽の影響も見られる。

複数のスマホで開く場合、各画面はそのスマホ自身を表示する。APの接続枠は右受信機1台とスマホ最大3台。右が接続待ちなら書き込んだ環境と電源を、両側または片側の値が「—」ならスマホが専用Wi-Fiに接続され画面を開いていること、および受信機との距離を確認する。シリアルモニターは115200 bps。

## 判定の仕組み

左は2.4 GHzのチャネル6で動作し、右はそこに接続して測定結果を400 msごとにUDP送信する。両方の受信機が、左AP宛ての上りデータフレームを送信元MACごとに集計する。ブラウザの約500 ms間隔の問い合わせが測定用の通信を兼ねる。左はDHCPのIP・MAC対応から表示対象を選ぶ。測定値はRAM上のみで保持する。

各受信機でRSSIを平滑化し、右RSSI − 左RSSI から中央の補正値を引く。差が +4 dB超なら右、−4 dB未満なら左、その間なら左右同程度と表示する。4 dBは実験用の初期値。各局が最近受信したフレームを比較する方式で、同一パケットの対応付けは行わない。片側の観測または右の通信が2.5秒以上途切れると判定を消す。

表示は左右の受信強度の傾向であり、距離や2次元座標を表さない。設置場所の反射、人体、基板やスマホの向きにより表示が逆転することもある。
