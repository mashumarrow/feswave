# 2026-11-10 実機記録

redmi-bench.csv はRedmi Note 10 JE上のCSV。動作確認用にPCから10秒間広告したID C0DEB105を、Redmi（0505FEC2）が4回受信した。中央値 −43.5 dBm、範囲 −44〜−43 dBm。逆方向もPCで同じRedmiのIDを受信した。配置距離・持ち方は未指定。

## Redmi Note 10 JE と Pixel 4

USB接続、手持ち、端末間1 mと3 mで各1試行。両端末で同時に20秒記録し、最初の5秒を除外した。pixel4.csv と redmi.csv は各端末から回収した全行で、Redmiのファイルは先行するPCとの動作確認も含む。
