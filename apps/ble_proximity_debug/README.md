# BLE 近接測定

Android 12以上のスマホ同士で、同じアプリが送信したBLE広告のRSSIを観察する。各端末が送信と受信を同時に行う。測定中にネットワーク接続は不要。

## インストール

Android SDKとJDKを用意し、このディレクトリで実行する。

```sh
mise install
mise exec -- flutter doctor
mise exec -- flutter pub get
mise exec -- flutter test
mise exec -- flutter build apk --debug
adb -s <serial> install -r build/app/outputs/flutter-apk/app-debug.apk
```

## 2台で測る

1. 両端末のBluetoothと位置情報をオンにし、アプリの「測定開始」を押す。付近のデバイスと使用中の位置情報（正確）を許可する。
2. 両画面の自端末IDと相手IDが対応することを確認する。IDは測定開始ごとに変わる。USBを外して以降の操作ができる。
3. 両端末で同じ距離と持ち方を選び、配置を決めて「20秒記録」をほぼ同時に押す。安定待ち5秒、集計15秒の間、端末の高さ・向きと人の位置を保つ。ポケットでは画面をロックせず収納する。
4. 手持ちで1 m→3 mを3往復し、ポケットでも同じ順で測る。測定停止は全試行の終了後に押す。ホームや画面ロックによる中断は試行結果に「中断」と記録される。
5. 各端末の画面下部で試行別の中央値、最小〜最大、集計件数を確認する。同じ受信端末・持ち方の1 mと3 mを対にして比較する。RSSIは数値が大きいほど強い。
6. 停止して「CSVを共有」からファイルを保存または転送する。CSVと結果履歴はアプリを閉じても残る。各端末の全セッションを1ファイルに追記する。

ライブ表示では直近5秒に3件以上ある相手を中央値順に並べる。1〜2件は集計待ち、5秒以上受信が途絶えた相手は受信待ち。試行結果には15秒間の受信件数をそのまま表示する。

## CSV

UTC時刻、イベント、観測側と相手の一時ID、セッション開始からの単調経過ミリ秒、試行番号、距離、持ち方、区間、RSSIを保存する。試行番号は観測側IDと組み合わせて識別する。試行外の受信は条件欄が空になる。試行は trial_start と trial_end の組で照合し、sample の phase が measure の行を集計する。trial_cancelled は中断。距離欄は実験者が指定した配置条件。

## 3台目がある場合

Aから1 mにB・3 mにCを置き、次にBとCの配置を交換する。Aで各配置10試行を記録し、近い側のIDと試行番号を控える。Aの画面の距離欄は近い端末の1 mに固定する（CSVの共通条件欄は相手個別の距離を表さない）。集計15秒内に両相手から各3件以上受信し、近い側の中央値が一意に大きい場合を正解とする。同点・受信不足も分母に含め、両配置とも8/10以上なら近い順表示の候補とする。
