# Pixel 4・Redmi Note 10 JE 実機検証

2台を手持ちで配置し、移動後15秒以上経ってから各端末が出した15秒中央値を比較した。各距離1試行。

| 端末間距離 | Pixel受信 | Redmi受信 | 両端末の同時タップ |
| --- | --- | --- | --- |
| 1 m | −67 dBm | −62 dBm | 両端末に共感メモリを保存 |
| 2 m | −86.5 dBm | −80 dBm | 両端末とも保存なし |

[距離別の集計値](distance.csv)と[5分間の観測窓](ble-windows.csv)。5秒ごとの60区間すべてで、両端末とも直近5秒以内に相手を受信した。CSVの age は集計時点での最終受信からの経過時間。

今回の2試行では仮の近接しきい値 −72 dBm を境に保存結果が分かれた。3台以上の順位、ポケット内、混雑会場での誤判定率は未評価。20曲の検証用プロフィールはGATT経由で転送し、1 m時の保存内容を端末のSQLiteで確認した。
